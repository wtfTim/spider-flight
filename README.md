# Spider Flight

Браузерная игра: поднимайся над городом на паутине, обходи препятствия и побеждай боссов.

**Играть:** https://wtftim.github.io/spider-flight/

## Управление

- Зажми левую кнопку мыши или коснись экрана для зацепа паутиной.
- Отпусти для свободного полёта и восстановления паутины.
- Shift или кнопка молнии — рывок.
- P — пауза, R — начать заново.

## Запуск и публикация

Открой [dist/index.html](dist/index.html) в браузере. Установка зависимостей и сборка не требуются.

При отправке изменений в ветку `main` GitHub Actions автоматически публикует содержимое `dist` в GitHub Pages.
